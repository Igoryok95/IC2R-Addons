# Vajra 32x32 remaster

Built-in imagegen edit. Input 1: original GraviSuite 16px Vajra enlarged only as a
readable reference. Input 2: native IC2R 32px iridium drill, material detail only.
The selected edit is retained unchanged in `source/vajra-remaster-reference.png`.
It is sampled once onto a native 32x32 grid, with binary alpha, as
`source/vajra-32.png`. The runtime icon uses those reviewed 32x32 pixels directly.
No enlarged 16px sprite is used as the final artwork.

## Exact selected prompt

Precise pixel-art texture edit. FIRST image is the edit target, the original GraviSuite Vajra enlarged from 16 pixels solely to make its shape readable. SECOND image is a native IC2R 32px material/detail reference. Preserve the FIRST image's broad, compact SINGLE oval frame, its proportions and diagonal position, the thick solid dark lower-right body/handle, central red core in the lower middle, and red angular wire in the upper-left open frame. The LOWER-RIGHT BODY MUST STAY SOLID OPAQUE GRAPHITE as in the original; do not turn it into a second hollow loop. Do not elongate the object into a long narrow wand or add a second frame, external coils, prongs or red end caps. Keep all the original holes in the upper oval genuinely alpha-transparent, as well as the exterior background. Upgrade ONLY pixel-level material detail to a true 32x32 logical pixel grid: add one-logical-pixel metal edge highlights, small bevels, a few red wire highlights and restrained dark handle shading INSIDE the original silhouette. It must be recognizable as exactly the same old Vajra, just painted natively at 32x32 instead of nearest-neighbor doubling a 16x16 drawing. A native 32px pixel-art sprite, crisp single-pixel detail; show enlarged with nearest-neighbor blocks, no soft edges, no small subpixel painting. All logical pixels equal size. Frame fills nearly the whole square canvas like the first image. Genuine transparent PNG; never paint transparent openings black, grey, white or checkerboard. No writing, no background, no glow, no anti-aliasing or gradients. Original red, charcoal and steel palette, restrained IC2R-style 32px detail. Preserve silhouette and transparency first.

## Verification

- RGBA PNG, 32x32, alpha restricted to 0/255.
- 168 independently detailed 2x2 cells; a doubled 16px icon has zero.
- 463 transparent pixels, including 90 enclosed pixels inside the frame.
- JUnit checks native detail, dimensions and real transparent openings.
- Actual first/third-person views and English/Russian item galleries are captured
  in the isolated client; documentation uses the English gallery.
