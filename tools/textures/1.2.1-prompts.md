# Quantum Solar Helmet palette reference

Tool: built-in imagegen, transparent output.

The final runtime icon is a palette edit of the existing Ultimate Solar Helmet, not a new
silhouette. The generated output supplies only its blue palette. `QuantumHelmet.java` retains
the restored classic 32x32 icon, alpha, worn armor UV coordinates and pixel placement.
The source artwork remains attributed as described in `NOTICE.md`.

Reference input: a nearest-neighbor strip of the existing Advanced, Hybrid and Ultimate
helmet icons with their item overlays composited. Output: `1.2.1-helmet-palette.png`.

## Exact prompt

Use case: precise-object-edit. Edit target: image 1, a reference strip of three existing Minecraft helmet inventory icons on transparency; the rightmost helmet is the ONLY source for the requested variant. Return only a single square transparent inventory sprite, exactly the same 32x32 logical pixel grid, same scale, front-facing shape, outline, faceplate and solar panel position as that rightmost existing Ultimate Solar Helmet. Make a minimal Quantum tier palette variant: change ONLY its dark navy solar crown to a slightly brighter electric blue and blue cyan, and slightly whiten the gray shell. Keep the rightmost silhouette EXACTLY, same simple front view, same sparse coarse pixels, same cyan center faceplate, same black lower opening, gray side ears. Do NOT redesign it, do NOT enlarge its occupied area, do NOT add a crest, do NOT add a visor, do NOT use 3D or diagonal perspective. The entire icon should fit within the same approximately 18x20 occupied logical pixels of a 32x32 canvas. Render enlarged with nearest-neighbor square logical pixels. No text, no glow, no shadows, no extra detail. Actual transparent background.

## Classic icon restoration

The final Hybrid and Ultimate icons use the exact classic designs from the user-provided
comparison in `source/classic-solar-helmets-reference.png`. `ClassicHelmets.java` copies
those designs onto a transparent 32x32 grid. The final Quantum icon is a palette variant of
that restored Ultimate icon. Generated reference geometry is never used.

## Reproduction

From the project root with Java 21:

```sh
java tools/textures/RefreshTextures.java
java tools/textures/ClassicHelmets.java
java tools/textures/QuantumHelmet.java
```

Final assets:

- `src/main/resources/assets/ic2r_addons/textures/item/quantumsolarhelmet.png`
- `src/main/resources/assets/ic2r_addons/textures/models/armor/quantum_solar_helmet_layer_1.png`
- `src/main/resources/assets/ic2r_addons/textures/models/armor/quantum_solar_helmet_layer_1_overlay.png`

`1.2.1-helmets-preview.png` is an enlarged comparison only, ordered Advanced, Hybrid,
Ultimate Hybrid and Quantum. Runtime inventory sprites stay 32x32.
